# Calculadora
Um programa de uma calculadora básica que consegue utilizar as 4 operações básicas, dizer se um número é par ou impar, comparar dois números, e tambem pode dizer se o número é sucessor ou antecessor do outro.

A lógica do programa tem base em python, utilizando while true oara criar um loop de repetição,def para funções especificas de escolha juntamente com match case para conseguir prosseguir com as escolhas condicionadas e ifs, elifs e elses par determinar certas condições dentro do proprio código.

Como exemplo ele consegue afirmar que a soma 100.0+100.1 seja igual a 200.1 .
